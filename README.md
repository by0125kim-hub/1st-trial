# 하루 계획

목표를 세우고, 하루를 단계별로 관리하는 작은 웹 앱이에요. 설치 없이 `index.html`을 브라우저로 열면 돼요.

0. **목표**: 채팅처럼 묻고 답하며 목표, 이유, 분야, 기한, 현재 상태, 쓸 수 있는 시간을 정리해요. 그러면 중간 목표와 할 일(1회, 매일, 매주)을 추천받아요.
1. **적기**: 생각나는 할 일을 모두 적어요.
2. **우선순위**: 높음, 보통, 낮음을 정해요. ('높음'은 3개 이하를 추천해요.)
3. **시간 배분**: 할 일을 누른 뒤 시간대(06:00~23:00)를 눌러서 배치해요.
4. **마무리**: 남은 일은 '했어요' 또는 '내일로'로 정리하고, 한 줄 회고를 남겨요.

밤 9시가 지나면 앱 안에 하루 마감 배너가 떠요. 새벽 4시 전까지는 전날로 취급해서, 자정을 넘겨도 그날 리뷰를 이어서 할 수 있어요.
데이터는 날짜별로 이 브라우저 안(localStorage)에 저장돼요.

## 할 일 추천
- **기본**: 앱에 들어 있는 분야별 추천이에요. 무료이고 설정할 것이 없어요.
- **AI 코치 · 내 Claude 계정**: Claude 안의 페이지(아티팩트, `claude-app.html`)로 열면, 로그인한 Claude 계정(Pro 등)의 사용량으로 AI 코치가 동작해요. API 키가 필요 없어요. 처음 쓸 때 한 번 허용을 물어요.
- **AI 코치 · API 키 (선택)**: GitHub Pages에서는 00 목표 화면 아래 'AI 코치'에 Anthropic API 키를 넣으면, Claude가 필요할 때 추가 질문을 하고(최대 2개) 목표에 맞춘 계획을 추천해요.
  - 키는 이 브라우저에만 저장되고 Anthropic으로만 전송돼요.
  - 사용량만큼 요금이 나오니 Anthropic 콘솔에서 월 사용 한도를 꼭 설정하세요.
  - AI 연결에 실패하면 기본 추천으로 대신 보여줘요.
- 추천받은 할 일은 **01 작성 → 목표에서 가져오기** 또는 목표 카드의 **+ 오늘**로 하루 계획에 넣어요.
- 목표의 할 일은 문구를 눌러 수정하고, 점을 눌러 우선순위를 바꾸고, 주기를 고르고, ✕로 지우고, 직접 추가할 수 있어요.
- **이어서 대화하기**: 저장한 목표에서 언제든 진행 상황이나 바뀐 점을 말하면, 최근 실행 기록과 이전 대화를 참고해 새 할 일, 중간 목표, 기한 조정을 제안해요.

## 오늘 할 일 편집
- 01 작성에서 ✎로 수정하고 ✕로 삭제해요. ⠿를 끌어서 순서를 바꿔요.
- 01 작성, 03 일정 배치, 04 하루 리뷰 맨 아래의 **이 날 초기화…**에서 무엇을 지울지 골라요: 시간 배치만 / 완료 표시만 / 회고·마감만 / 전체(두 번 누르기).
- 03 일정 배치에서 할 일을 시간대로 끌어다 놓고, ⠿를 끌어 다른 시간으로 옮기거나 위쪽 칸으로 끌어서 배치를 취소해요. 마우스와 손가락 모두 돼요.

## 구글 캘린더 연동
- **일정 블록 → 캘린더**: 시간표 블록의 `+ 캘린더`를 누르면 해당 시간의 일정이 채워진 구글 캘린더 화면이 열려요. 저장하면 끝이에요.
- **매일 23:55 리뷰 알림**: `캘린더에 등록`을 한 번 누르면 매일 반복 일정이 만들어져요. 앱을 닫아둬도 캘린더가 알려줘요.
- **리뷰 기록**: 하루를 마감한 뒤 `리뷰 결과를 구글 캘린더에 기록`을 누르면 완료, 이월, 회고 내용이 그날의 종일 일정으로 남아요.

## 파일

- `drag.js`: 끌어서 옮기기
- `claude-app.html`: Claude 안에서 여는 버전 (화면과 코드는 같아요)
