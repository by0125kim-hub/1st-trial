# 하루 계획

하루를 4단계로 관리하는 작은 웹 앱이에요. 설치 없이 `index.html`을 브라우저로 열면 돼요.

1. **적기**: 생각나는 할 일을 모두 적어요.
2. **우선순위**: 높음, 보통, 낮음을 정해요. ('높음'은 3개 이하를 추천해요.)
3. **시간 배분**: 할 일을 누른 뒤 시간대(06:00~23:00)를 눌러서 배치해요.
4. **마무리**: 남은 일은 '했어요' 또는 '내일로'로 정리하고, 한 줄 회고를 남겨요.

밤 9시가 지나면 마무리를 하라는 알림 배너가 떠요.
데이터는 날짜별로 이 브라우저 안(localStorage)에 저장돼요.

## 파일
- `index.html`: 화면 뼈대
- `style.css`: 디자인
- `app.js`: 동작
