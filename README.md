# 하루 계획

하루를 4단계로 관리하는 작은 웹 앱이에요. 설치 없이 `index.html`을 브라우저로 열면 돼요.

1. **적기**: 생각나는 할 일을 모두 적어요.
2. **우선순위**: 높음, 보통, 낮음을 정해요. ('높음'은 3개 이하를 추천해요.)
3. **시간 배분**: 할 일을 누른 뒤 시간대(06:00~23:00)를 눌러서 배치해요.
4. **마무리**: 남은 일은 '했어요' 또는 '내일로'로 정리하고, 한 줄 회고를 남겨요.

밤 9시가 지나면 앱 안에 하루 마감 배너가 떠요. 새벽 4시 전까지는 전날로 취급해서, 자정을 넘겨도 그날 리뷰를 이어서 할 수 있어요.
데이터는 날짜별로 이 브라우저 안(localStorage)에 저장돼요.

## 구글 캘린더 연동
- **일정 블록 → 캘린더**: 시간표 블록의 `+ 캘린더`를 누르면 해당 시간의 일정이 채워진 구글 캘린더 화면이 열려요. 저장하면 끝이에요.
- **매일 23:55 리뷰 알림**: `캘린더에 등록`을 한 번 누르면 매일 반복 일정이 만들어져요. 앱을 닫아둬도 캘린더가 알려줘요.
- **리뷰 기록**: 하루를 마감한 뒤 `리뷰 결과를 구글 캘린더에 기록`을 누르면 완료, 이월, 회고 내용이 그날의 종일 일정으로 남아요.
